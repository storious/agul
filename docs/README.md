# Agul documentation

The project README is the shortest path to running Agul. Each topic below has
one reference page so setup and runtime behavior are not repeated across the
documentation:

- [Chat and tools](chat.md) covers the terminal workbench and model options.
- [ChatGPT account mode](codex-account.md) covers Codex allowance and live Web
  Search.
- [Skills and launches](skills.md) covers runtime launches, Skill discovery,
  precedence, and virtual System Skills.
- [Plugins](plugins.md) covers external tool manifests and process I/O.
- [Sessions and usage](sessions-and-usage.md) covers history, compaction, tokens,
  and cost.
- [ARI](ari/README.md) covers the stdin/stdout integration surface.
- [Self-maintenance](self-maintenance.md) gives a practical checkout workflow
  and delegation guidance.
- [Release notes](release.md) are used as the detailed GitHub Release body.
- [Demo recording](demo/README.md) documents the deterministic GIF fixture and
  its cache-telemetry contract.
